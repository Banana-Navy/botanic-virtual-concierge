# Botanic Virtual Concierge

English landing page for the Botanic Virtual Concierge concept, designed by Banana Navy for Botanic Sanctuary Antwerp.

The public page presents the proposed guest experience, reference technology architecture and trust controls. It is a private concept preview and not an operational hotel service.

## Public site

https://banana-navy.github.io/botanic-virtual-concierge/

## Local preview

Serve this directory with any static HTTP server. For example:

```sh
python3 -m http.server 4173
```

Then open `http://127.0.0.1:4173/`.
